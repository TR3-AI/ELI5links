Who is the independent reviewer? 🪑

first, a "seat" is just a job — not a "sheet"

🪑

What "seat" means

A seat is a job in the team — one worker, one chair, one job. (I typed "seat," like a chair at the table — not "sheet" of paper.) Some seats plan, some seats build, and one seat reviews.

⬇️
📐

The plan seat

One seat writes the detailed plan — exactly what each piece should do. That's the Full SDD seat. Think of it as the one who draws the blueprint.

⬇️
🔨

The build seats

Other seats write the actual code (Feature Tickets + Green Pass). They follow the plan. They are not the same worker who drew the blueprint.

⬇️
🧑‍⚖️

So who reviews? The plan seat.

At the end, someone must check: "does the code match the plan?" The best judge is the Full SDD seat — it wrote the plan (knows it cold) but didn't write the code. So it's honest — it isn't marking its own homework. That's what "independent" means.

⬇️
🏠

Like building a house

The architect draws the blueprint. Builders build it. At the end the architect walks through and asks "does this match my blueprint?" — they know the plan by heart and they didn't lay the bricks. Perfect, fair judge.

⬇️
👔

Then what does the manager do?

The manager is the boss. It does not read the code itself. It hands the code to the Full SDD seat and won't let anything move forward until the check passes. That's all "the manager owns the gate" means.

⬇️
✅

The whole thing, plainly

Two checks on the finished code: a robot (Greptile) scores if it's tidy; the Full SDD seat says if it matches the plan. The manager makes sure both happen. Nobody checks their own work.

Short version: a seat = a job. The independent reviewer = the Full SDD seat (wrote the plan, not the code). The manager owns the gate but doesn't read the code.
