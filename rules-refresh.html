Getting new rules to every team 🔄

how a rulebook change reaches teams that are already working

1 🔕

The gap we closed

When the shared rulebook changed, teams already working didn't hear about it. They kept going on the old rules until someone set them up fresh.

⬇️
2 📣

Now it goes through Ops

You tell Ops "push the new rules." Ops is the one desk that can reach everyone: you → Ops → every manager.

⬇️
3 🔄

One command, one shot

Ops runs a single refresh. It pings every team manager once — then stops. No spam, no loop left running.

⬇️
4 ✅

Each team catches up

Every manager pulls the latest rules, loads them into their team, and confirms back to Ops when they're on the new rules.

⬇️
5 🔌

Fresh by default too

Any time a team seat gets set up, it now grabs the newest rules first — so nobody ever starts on a stale copy.

⬇️
6 ♻

No new plumbing

This reuses the message system Ops already has for its regular check-ins — no new services, no extra moving parts. 120 automated checks pass.
