📋

What “done” means

Not just “I think I’m finished.” Every box is ticked: it has a plan, it actually works, the tests pass, it’s saved, it passed its grade (the PR gate), and nothing’s left over.

⬇️
📝

Not like the sticky note

The “where I stopped” note? You write it, nobody checks it. “Done” is the opposite — other people build on it, so it’s never done just because you say so.

⬇️
🚫

The big rule

You don’t mark your own homework. Someone else always checks before it counts as done.

⬇️
🧱

One job (a ticket)

The person who did the job ticks the list.

worker ticks it → manager checks the real thing → ✅ done

⬇️
📦

A whole batch (a phase)

The manager ticks the list for the whole batch.

manager ticks it → you give the 👍 → ✅ done

⬇️
👍

Nobody grades themselves

The worker is checked by the manager. The manager is checked by you. Clean and simple.

Still your call: who gives the final 👍 on a whole batch.
