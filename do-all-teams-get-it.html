How a worker starts its shift

Every time a worker starts, it's handed two things fresh: the shared rulebook and its own job card. It doesn't work from memory — it gets a clean hand-out each time it clocks in.

⬇️
📖

The rulebook is always the latest

The shared rules (the merge rules + the big rulebook) are pulled straight from the master copy every single time a worker starts. So nobody works from a stale copy. I just refreshed the shared copy, so it's current right now.

⬇️
🪧

The job card comes from the template

What each seat does comes from the installed template. I updated it and re-installed it — so the cards handed out now include the new plan-check.

⬇️
🆕

New teams — everything

A brand-new team is built straight from the updated template and pulls the latest rules. It gets the whole thing, no extra step.

⬇️
👋

SM & HAP — yes, next clock-in

They're real teams (they have their own memory folders). They use the same shared rules and the same installed template — so they get the new rule the next time their workers start up.

⬇️
⏸️

One catch: mid-shift doesn't change

A worker already running right now won't change in the middle of its shift. It picks up the new rule when it next starts (restart / hand-off). Nothing changes live under a working agent.

⬇️
🗄️

Their old saved copy is stale — but unused

Each team keeps an old copy of its job card in its drawer from setup day. It's outdated — but that's not what they work from; they work from the fresh hand-out at start-up. I can tidy the drawers too if you want, but it's not needed.

Short version: everyone gets the latest rules + card handed fresh when they start. New teams: automatic. SM & HAP: next start-up. Only a worker mid-shift waits till it next starts.
