How the watcher watches 👀

it watches your saved code — not your keystrokes

Part 1 · does it watch as the AI codes?

idea — not built yet 🙈

It doesn't watch you type

It can't see the AI's thoughts or every keystroke. That's not how it works.

⬇️
📁

It watches your local folder

The folder on your machine where edits get saved. Not GitHub (that only updates when you push). Not the Graphify map (a snapshot made after the fact — handy to explain a break, but not where edits land).

⬇️
🙉

It skips the noise

It ignores .git, target, virtualenvs, graphify-out, and its own reports — so its own output can't set it off in a loop. It watches your source, tests, and config.

⬇️
⏸️

It waits for you to stop

An AI often saves several files at once. It waits for a breath of quiet first — so it rarely checks a half‑finished state (waiting can't rule it out completely).

⬇️
🔄

Newest version only

Saved again mid‑check? It throws away the old check and restarts on the latest. One check, on the freshest code.

⬇️
✅

Then it checks that snapshot

Build → quick lint → tests, on that newest saved version. That's one full look.

⬇️
🔬

Debugger only if it must

A compile error or a red test just gets reported. Only a real crash or freeze gets the debugger. So it's not heavy every time.

Part 2 · does everyone have a compiler?

🦀

Rust — strict compiler

Checks a lot before it runs: misspelled names, wrong case, wrong types. It won't build if something's off.

⬇️
🐹

Go — a compiler too, lighter

Go also compiles, so it also catches misspelled names, case, and types before running. Less strict than Rust — but it even barks at unused imports.

⬇️
🐍

Python — only syntax up front

Python does compile to bytecode — but that only catches syntax. Wrong names or types aren't caught until that line runs (a NameError). The watcher adds ruff (names) and mypy (types) to catch them earlier.

⬇️
🏷️

But not every “wrong name”

A compiler catches a misspelled variable or function. It can't tell a wrong filename, config key, API field, or DB column — those look fine. Those need a test, type, or schema, like any quiet bug.

🎯

The short version

It watches your local folder (skipping build junk and its own reports), waits till you stop saving, then checks the newest version once — debugger only for crashes or freezes. Rust & Go compilers catch misspelled names and wrong‑case before running; for Python the watcher adds ruff + mypy. Wrong values (filenames, config, fields) still need a test or schema.
