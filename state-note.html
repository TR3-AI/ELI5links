The state note
— where I stopped 📝

so anyone can pick the task back up

📝

What it is

A short note that says exactly where a task was left. You write one every time you stop, pause, finish, or complete a task — yes, even when it’s done, not just when you stop.

⬇️
✍️

Who writes it

The person doing the work, right at that moment. They write and sign it themselves — it’s never handed to someone else afterwards. (I write it for manager-level work.)

⬇️
🐙

Where it lives

Saved to GitHub — in the team’s private memory, a shared drop-box everyone on the team can open. Not the notes Vault. Save your work first, then the note goes up too, so it can never get lost.

⬇️
📋

What goes in it

👤 who wrote it + which seat
🎯 phase / step, and status
📈 how far along (%)
🌱 branch + last saved commit
🔗 links: PR / ticket / SDD
🌐 this chat’s session ID
✅ what was done + what’s next
📜 last 3 handoff summaries
💬 chat history for the task
⚠️ watch-outs (bugs, gotchas)
🚧 blockers + missing bits

who writes it = the agent doing the work, every stop / pause / finish / complete 🐶
