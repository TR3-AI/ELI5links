The bug‑watcher — the whole thing 🔭🐛

the whole idea, in the simplest words

what it is

idea — not built yet 🔭

A helper that watches your code

As you (or an AI) write code, it checks the work and catches bugs on its own.

where & when it looks

👀

It watches your saved files

The real files in your folder on this computer. Not GitHub, not a map — just the files, as they're saved.

⬇️
⏸️

It waits till you stop saving

Then it looks at the newest version — not your keystrokes, not half‑saved work. It also skips junk folders and its own notes, so it can't loop.

what it does

🧪

Three quick checks

Does it build? Does the lint pass? Do the tests pass?

⬇️
💥

It catches the loud stuff

A crash, a failed test, or a freeze (a timer spots the freeze). The noisy bugs.

⬇️
🔬

Only a crash or freeze → debugger

Then it replays under the debugger to find the exact spot. CodeLLDB (Rust), Delve (Go), pdb (Python).

the three languages

🦀

Rust — strict compiler

Catches typos and wrong types before it runs.

⬇️
🐹

Go — a compiler too, lighter

Also catches typos and types before running — just less strict.

⬇️
🐍

Python — fewer checks before running

Python checks the whole file for syntax first — but usually not wrong names or types; those only show up when the line runs. So the watcher adds a linter (ruff) and a type checker (mypy) to catch those earlier. Weaker than a real compiler — tests still matter.

after it finds something

📝

It writes one tidy note

What broke and where (file + line when it can) — read straight from each tool's output.

⬇️
🔧

You or the AI fix it

The watcher finds, it doesn't fix your logic. It hands the note to the coder. Only tiny, safe fixes it does itself.

⬇️
🔁

Then it checks again

Fix → it re‑runs → green means done. That's the loop.

🎯

The short version

It watches your saved code, waits till you stop, then runs build + lint + tests on the newest version. It catches crashes, red tests, and freezes, writes one clear note of what broke and where, and hands it to you or the AI to fix — then checks again. It won't catch quiet wrong answers — those still need a test.
