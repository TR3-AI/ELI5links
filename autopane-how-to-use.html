Auto-Fill:
how to use it 🧩

start it, pick the right tab, and the on/off switch

🧩

What it does

Grows the tab you're in up to the full team of nine — keeps your open windows and their work, adds the ones you're missing.

⬇️
⌨️

1. How do I start it?

You type it. In the tab you want, type /autopane fill. Just opening a window does nothing — only typing the words starts it.

⬇️
🪟

2. A new tab, or one I'm using?

One you're already using. It works on the tab you typed it in, and reshapes that whole tab into the full nine.

⬇️
🔒

Your work is safe

It never closes or restarts your windows. Your old ones keep working; only the brand-new ones start up fresh.

⬇️
🚦

Two little rules

If the tab is already nine → it does nothing. If it has more than nine → it leaves it alone. Otherwise it tops you up to nine.

⬇️
🔀

3. Is there an on/off switch?

Yes — type /autopane status to see ON or OFF. /autopane off and /autopane on flip it.

⬇️
⭐

The catch worth knowing

The switch only controls the automatic part — whether a brand-new tab fills itself. It does not touch Fill: /autopane fill works whether the switch is ON or OFF. You can leave it OFF for good and still fill any tab whenever you like.

⬇️
🔁

One gotcha

The command loads when a window starts. If a window was already open before, restart it once so it knows the word.

⬇️
✅

Your four words

/autopane fill status on off

fill = grow this tab · switch = auto-build new tabs 🐶
